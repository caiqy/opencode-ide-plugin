# API 文档指针

本页只给 API/schema 契约的真源指针，不手抄请求/响应表，避免 rot。

## opencode HTTP API

opencode HTTP API 的契约由 server 路由和 schema 生成。

server 侧使用 Hono，并通过 `hono-openapi` 描述路由。

生成后的 OpenAPI 规范在：

- `../../../packages/sdk/openapi.json`

SDK 由 `@hey-api/openapi-ts` 从该规范生成到 `@opencode-ai/sdk`。

legacy 生成代码在：

- `../../../packages/sdk/js/src/gen/**`

v2 生成代码在：

- `../../../packages/sdk/js/src/v2/gen/**`

生成脚本入口可从以下文件追踪：

- `../../../script/generate.ts`
- `../../../packages/sdk/js/script/build.ts`

这些生成文件头部标注 `This file is auto-generated by @hey-api/openapi-ts`。

## WebGUI SDK 封装

WebGUI 不直接把所有调用散落到组件里。

它通过以下文件二次封装 SDK：

- `../../../packages/opencode/webgui/src/lib/api/sdkClient.ts`

该封装保留 SDK client，同时补齐部分 WebGUI/插件需要的接口包装。

多数包装返回统一的 `{ data, error }` 形状，便于 UI 层处理加载、失败和空数据。

涉及 MCP、Skills、path、global config、session retry/visibility 等插件侧适配时，先看这个封装再追后端路由。

## IDE Bridge 协议

IDE Bridge 不是 HTTP OpenAPI。

它是 WebGUI 与 VSCode/JetBrains 宿主之间的自定义消息协议：WebGUI 通过 POST 发请求，Host 通过 SSE 推送事件。

协议字段、`connected` 元数据、`restartMode`、`storageGet/storageSet`、`saveImage`、更新请求等维护入口见：

- [business/ide-bridge.md](business/ide-bridge.md)
- [hosts-vscode-plugin 参考](repositories/hosts-vscode-plugin.md)

新增 bridge 消息时，需要同时评估 WebGUI、VSCode、JetBrains 三端，而不是改 OpenAPI。

## 更新提醒

修改 skill、mcp 等 HTTP 契约后，要同步 `../../../packages/sdk/openapi.json` 和 v2 生成目录 `../../../packages/sdk/js/src/v2/gen/**`。

legacy 生成目录 `../../../packages/sdk/js/src/gen/**` 仍服务旧客户端形状。

除非单独做 SDK 迁移，不要在普通功能修复中重生成 legacy gen，以免破坏现有 WebGUI/插件调用方式。

知识库页面引用 API 时优先链接上述真源；需要字段级细节时读生成规范或生成 SDK，不在本文复制表格。
