# Changelog

## v26.5.1800

### 修复与体验优化
- 改进消息列表自动滚动、滚动锚点与窗口尺寸变化后的尾部跟随稳定性，减少长回复、连续新消息和面板尺寸变化时的滚动跳动与位置漂移。
- 修复图片预览关闭时的稳定性问题，降低查看图片后关闭浮层时出现异常状态的概率。
- VSCode 插件现在会在 UI user agent 中带上插件版本号，便于后端识别版本来源并改进问题诊断。

## v26.5.1602

### 修复与体验优化
- 改进 assistant 自动跟随滚动稳定性，减少长回复流式输出时的视图跳动与丢焦。
- 为中断后的消息加载补上更稳妥的重试处理，降低历史消息拉取被异常终止后的恢复成本。
- 修复 Markdown 图片预览相关稳定性问题，减少含图片内容的消息在 IDE 内展示异常。

## v26.5.501

### 修复与体验优化
- 状态弹层现在会显示插件当前实际连接的后端目标，便于在本地开发、远程环境和多后端场景下快速确认连接对象。
- 修复任务列表中待完成任务的状态图标在消息卡片与底部面板里的偏移和裁切问题，确保 pending 圆环完整且对齐显示。
- assistant 回复底部现在会按本地日期显示更直观的完成时间：今天、昨天、前天显示相对日期，更早记录显示完整日期与时间，便于快速判断回复结束时刻。

## v26.5.303

### 近期重点改进
- 补齐 JetBrains 宿主侧能力，持续向 VSCode 端体验对齐。
- 支持 host-aware 重启动作，在不同宿主环境下提供更准确的重启入口。
- 继续完善中文本地化，补齐模型、工具权限、错误提示等关键文案。

### 功能演进概览
- 支持文件拖拽加入上下文、当前文件加入上下文、已打开文件批量加入上下文，以及选中代码行范围加入上下文。
- 完成浏览器式标签体系建设，支持拖拽、重命名、右键菜单、自动滚动与数量限制。
- 引入快捷短语、子任务抽屉、任务进度头与更易编辑的输入区域，提升日常使用效率。
- 统一宿主侧状态持久化策略，改进主题、设置、会话与草稿状态恢复体验。

### 修复与体验优化
- 优化常用短语预设，提升 IDE 内提示词输入效率。
- 增强 WebView 滚动体验并支持 `jcefScrollMultiplier` 参数调节滚动灵敏度。
- 改进流式输出、会话恢复、标签状态持久化与长会话稳定性。
- 移除旧的仅界面变体说明，统一标准版单路线发布文案与打包认知。
