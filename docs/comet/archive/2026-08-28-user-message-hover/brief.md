# Outcome

调整 WebGUI 主会话和子任务抽屉中用户消息的 hover 元信息布局，使时间和消息操作位于用户消息气泡下方；主会话保留既有操作并新增重试能力，子任务抽屉只保留复制。assistant 消息 hover 时不再显示操作控件。

- assistant 消息 hover 操作控件的移除。
- 桌面 hover、键盘 focus 和无 hover 触摸设备的可访问显示。

# Non-goals

- 不新增编辑操作或改变服务端协议。
- 不改变复制、分叉、回退的业务逻辑。
- 不改变消息数据结构、消息排序或已有会话撤销流程。

# Acceptance examples

- A1: 主会话支持 hover 的设备上，鼠标移入用户消息后，时间和五个操作图标显示在气泡下方，而不是气泡上方。
- A2: 主会话元信息行右对齐，顺序为本地时间、复制、分叉、回退、重试，且不使用外层灰色工具栏背景。
- A3: 时间取用户消息的 `time.created`，使用浏览器本地时区并按 `M月D日 HH:mm` 格式显示。
- A4: 复制、分叉、回退按钮及其 tooltip 继续执行现有功能，操作逻辑不变。
- A5: 主会话所有用户消息都显示重试按钮；点击后先打开确认弹窗，确认后才将该消息的原文本和附件作为新的 prompt 追加到当前会话末尾。
- A6: 对话未停止时重试按钮保留但禁用；对话停止后可点击重试。
- A7: 重试确认弹窗支持确认、取消和关闭；取消或关闭不得发送新的 prompt，确认期间显示加载状态并阻止重复确认。
- A8: assistant 消息 hover 时不再显示任何操作控件，包括复制和令牌用量控件。
- A9: 主会话无 hover 的触摸设备上，用户消息时间和五个操作图标可见且可访问；键盘 focus 时元信息可见。
- A10: 主会话用户消息元信息处于正常文档流，不遮挡文本或附件；窄屏下可换行且图标点击区域不收缩。
- A11: 子任务抽屉用户消息在气泡下方显示本地时间和复制按钮，不显示分叉、回退或重试按钮。
- A12: 子任务抽屉用户消息复制按钮继续可用，并遵循支持 hover、键盘 focus 和触摸设备的可访问显示规则。

# Constraints and invariants

- 用户消息仍保持现有气泡、文本、附件和右侧布局语义。
- 操作按钮必须保留可访问名称、tooltip 和稳定点击区域。
- 主会话重试必须复用现有会话 prompt 发送流程，不改变原消息或历史排序。
- 主会话重试仅在会话停止后可执行，运行中的会话不得重复触发发送。
- 子任务抽屉用户消息只提供复制，不提供分叉、回退或重试。
- 重试必须先经过确认弹窗，确认前不得调用 prompt。

# Decisions

- 采用截图一的结构：元信息显示在用户消息气泡下方并右对齐。
- 保留复制、分叉、回退三个现有操作及其相对顺序。
- 重试追加在回退之后，作为用户消息元信息行的第五个操作。
- 所有用户消息都提供重试；旧消息重试会将原文本和附件作为新 prompt 追加到当前会话末尾。
- 重试按钮点击后先显示确认弹窗；确认后才发送，取消或关闭不发送。
- 仅主会话用户消息提供重试；子任务抽屉用户消息只提供复制。
- 对话未停止时重试按钮保留但禁用。
- assistant hover 时移除复制和令牌用量两个现有控件，不再显示任何操作控件。
- 支持 hover 的设备仅在用户消息 hover 或键盘 focus 时显示元信息；触摸设备常驻显示。
- 操作栏移除外层灰色背景，单个图标继续显示 tooltip。
- 时间格式固定为 `M月D日 HH:mm`，时间源为 `time.created`，时区为浏览器本地时区。
