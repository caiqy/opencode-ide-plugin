# Outcome

WebGUI 聊天输入区采用统一的 Copilot 风格 composer。快捷短语、附件、文本编辑和底部工具栏形成稳定层级，保留现有发送、停止、会话设置、上下文压缩和附件能力。

# Scope

- 重组 `packages/opencode/webgui` 的 MessageInput 视觉结构和控件顺序。
- 将快捷短语作为统一外框内的紧凑顶栏。
- 调整任务摘要与快捷短语的主题背景、分隔线和任务状态图标。
- 将图片附件显示为文字上方的可删除、可点击放大缩略图。
- 调整 Agent、模型、variant、上下文用量、压缩和发送/停止控件的表现。
- 为新增或变化的可观察行为补充测试，并检查桌面与窄屏布局。

# Non-goals

- 不改变消息提交、停止生成、会话切换、模型选择或上下文压缩的业务语义。
- 不新增附件协议、附件数据结构、图片预览弹窗或第三方依赖。
- 不实现自动审批逻辑、权限自动回复或状态持久化。
- 不重做消息列表、会话侧栏或 WebGUI 其他页面。

# Acceptance examples

- A1: composer 使用统一容器，内部从上到下依次为按需出现的任务摘要、快捷短语顶栏、按需出现的附件轨道、文本编辑区和底部工具栏；首个可见面板继承容器左右上 8px 圆角，因此有无任务摘要时 Composer 均保持左右上圆角。任务摘要与快捷短语在浅色主题为白色、深色主题为 `rgb(30, 30, 30)` 背景；快捷短语按钮在深色主题使用 `rgb(26, 26, 26)` 底色；快捷短语与编辑区之间仅使用 1px 弱分隔线。下半编辑区和工具栏没有独立内框或强分割线。聚焦蓝色边框只包裹下半编辑区，不得覆盖任务摘要或快捷短语顶栏。
- A2: 快捷短语 chip 高 24px、间距 6px，默认使用中性灰样式；收起时保持单行横向滚动和拖动，展开按钮为 Chevron 图标，既有双击发送和右键双击回填行为保持可用。
- A3: 底栏左侧按 `+` 附件、Agent、模型、variant、自动审批的顺序显示；Agent、模型和 variant 不显示下箭头但仍可点击切换；自动审批显示为禁用控件并提示“自动审批（暂未启用）”。
- A4: 底栏右侧按无数字上下文进度环、Shrink 上下文压缩按钮、圆形发送/停止按钮的顺序显示；进度环使用固定 2px SVG 描边。已使用描边在 50% 开始呈浅黄（`#fef3c7`），60% 为黄峰值（`#facc15`），60%-80% 均匀过渡至红色（`#ef4444`），80% 及以上保持红色；50% 以下保持主题中性描边，未使用部分保持 `rgba(255,255,255,.32)` 的深色主题对比色。实际百分比通过 tooltip 和可访问名称提供，原有压缩、发送和停止行为保持。
- A5: 粘贴或选择的图片在文字上方显示为 72x72px 缩略图，右上角有删除按钮，点击可通过现有图片 overlay 放大；多图单行横向滚动，非图片附件继续显示文件 chip，失败预览使用现有失败状态。
- A6: 没有附件时不保留空附件轨道；composer 随文本和附件合理增高，并在桌面和窄屏下无控件重叠、意外换行或主操作被挤出。
- A7: 相关组件测试覆盖快捷短语既有交互、附件缩略图/删除/放大、非图片附件、工具栏顺序、自动审批禁用态，以及发送/停止切换；目标 package 的适用测试和 typecheck 通过。
- A8: 任务状态使用可辨识图标：完成为绿色勾选，进行中为蓝色圆环内时钟，待办为灰色圆环内实心点；完成项没有删除线，进行中保持低调蓝色行强调，不显示优先级、难易程度或文件变更入口。

# Constraints and invariants

- 沿用 WebGUI 的深色中性配色；蓝色只用于聚焦、hover 或主操作状态。
- 使用现有选择器、上传输入、`ImagePreview`、`ImageOverlay`、上下文统计和压缩动作。
- 图标按钮必须有 tooltip、`aria-label` 和稳定点击区域。
- 参考图位于 `.opencode/generated-images/webgui-composer-final-plus-attachment-msg_0055822a2001gnzo245hps50Fl-42370656.png`，仅作为布局方向，不覆盖本 brief 的明确要求。
- 遵循仓库现有 React、Tailwind 和测试模式，不添加新依赖或无关抽象。

# Decisions

- 快捷短语采用统一外框顶栏，而不是外置条带或工具栏浮层。
- 快捷短语使用更紧凑的中性 chip，展开/收起改为图标按钮。
- 图片附件位于文字上方，点击复用现有 overlay 放大，多图横向滚动。
- 附件入口改为底栏最左侧的 `+` 图标，移除原回形针位置和相邻竖分隔线。
- Agent、模型和 variant 使用左侧语义图标，不显示下箭头。
- 上下文用量只显示小型进度环，不在环内显示数字；使用固定 2px SVG 描边，50% 起渐黄、60% 为 `#facc15`、80% 为 `#ef4444` 并保持红色；50% 以下已使用部分与未使用部分保持主题中性对比色。
- composer 深色主题背景使用 `dark:bg-gray-900`，比消息正文的深色背景浅一档；不增加额外内框或改变输入区布局。
- 首个可见 Composer 面板继承容器左右上 8px 圆角，确保有无任务摘要时顶部圆角一致；任务摘要与快捷短语顶栏在浅色主题使用白色、深色主题使用 `rgb(30, 30, 30)` 背景，快捷短语按钮在深色主题使用 `rgb(26, 26, 26)`；快捷短语与编辑区之间仅保留 1px 弱分隔线，编辑区独立承载默认边框和聚焦蓝色边框。
- 上下文压缩使用四角向内的 Shrink 图标；发送按钮使用小型圆形样式。
- 自动审批本次只做禁用 UI，后续 change 再定义和实现行为。
