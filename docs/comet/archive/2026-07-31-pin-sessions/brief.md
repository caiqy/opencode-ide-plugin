# Outcome

在历史会话下拉列表中提供钉住与取消钉住能力；钉住的根会话始终排在未钉住会话之前。

# Scope

- `packages/opencode/webgui` 的历史会话下拉列表、会话行操作和实时状态同步。
- 会话列表的数据排序与分页边界，确保旧会话被钉住后不会因首屏更新时间分页而消失。
- 保存钉住状态所必需的最小 Session/API 行为。

# Non-goals

- 不改变历史会话搜索的标题匹配规则。
- 不改变会话行右侧当前显示的创建时间。
- 不增加批量钉住、钉住分组管理或手工拖拽排序。
- 不把当前不会出现在该列表中的子会话加入历史列表。

# Acceptance examples

- 已钉住会话 A 的最后更新时间早于未钉住会话 B 时，A 仍显示在 B 前面。
- 搜索命中钉住和未钉住会话时，匹配结果仍先显示钉住会话。
- 用户可以从会话行明确识别钉住状态，并执行钉住或取消钉住。
- “加载更多”后，钉住会话仍组成列表最前面的连续区域，不会混入未钉住会话之后。

# Constraints and invariants

- 未钉住会话继续沿用现有 `time.updated` 降序语义。
- 钉住会话内部同样按 `time.updated` 降序；钉住或取消钉住本身不得改写最后活动时间。
- 当前会话不因选中状态被隐式钉住。
- 搜索只缩小候选集合，不改变同一候选集合的钉住优先级。
- 使用现有会话事件同步链路，避免刷新页面才能看到钉住状态变化。
- 复用 Session 已有的开放 metadata 扩展能力，不增加旧版官方 `opencode app` 必须识别的响应字段；旧客户端忽略钉住键时不得报错。
- 只改变 WebGUI 使用的项目会话列表排序；官方 `opencode app` 可忽略钉住 metadata，并继续使用其现有客户端更新时间排序与分页行为。

# Decisions

- 项目配置选择 Comet Native 工作流。
- 功能目标是截图所示 `CompactHeader` 历史会话下拉列表。
- 钉住是显式用户状态，不等同于最近活跃或当前选中。
- 钉住状态随 Session 持久保存；同一数据目录下的客户端共享，IDE 或服务重启后仍保留。
- 官方 `opencode app` 不增加钉住入口，也不要求采用钉住排序；它必须能忽略钉住 metadata 并正常使用会话。
- 钉住组内部继续按最后更新时间降序，钉住/取消钉住操作本身不计为会话活动。
- 已钉住会话在标题旁常驻显示小图钉；切换按钮放在现有悬浮/当前会话操作区。
- 新建会话和从已钉住会话 fork 的会话默认不钉住；fork 保留其他 metadata，但移除钉住键。
- 钉住/取消钉住成功后仅用图钉和排序变化反馈；失败时保留原状态并显示中文错误 toast。
- 用户已确认本 brief 与 `session-pinning` 完整目标规格，可进入实现。

# Verification expectations

- 覆盖钉住优先、未钉住更新时间排序、搜索过滤和加载更多后的顺序。
- 覆盖会话行钉住/取消钉住操作、状态标识及失败时不产生错误的本地状态。
- 验证钉住状态随会话持久保存，并验证旧客户端可忽略钉住 metadata 而正常读取会话。
- 验证项目会话查询在分页截取前完成钉住优先排序，且不改变官方 app 使用的全局会话列表契约。
