# Outcome

在现有设置面板增加可见的“常用设置”入口，集中配置自动更新、文件快照、搜索模式、网页搜索并行数、子任务并行数和错误重试上限；每项均提供足以说明作用、默认值和影响的中文说明。

# Scope

- 设置面板导航、常用设置表单、全局配置保存及缺省值行为。
- 自动更新默认开启，文件快照默认关闭，搜索模式默认 OpenAI 搜索。
- 网页搜索和子任务并行数默认均为 3；错误重试上限默认 10 次。
- 为新增或调整的用户可见行为补充聚焦测试。

# Non-goals

- 不重做整个设置面板或 Provider、Agent、快捷短语页面。
- 不新增搜索供应商、重试算法或并行队列实现。
- 不改变正在执行中的搜索、子任务或模型请求。

# Acceptance examples

- A1：设置面板展示可访问的“常用设置”入口，打开后可看到本需求全部配置项。
- A2：每个配置项始终显示中文说明，说明包含用途、默认值和关键影响，不依赖悬停才能读取。
- A3：未显式配置时，自动更新控件与实际更新行为均按最终确认的对象默认开启；保存后对应配置生效。
- A4：未显式配置时，文件快照控件为关闭，后续会话不记录文件快照；开启并保存后，后续会话恢复快照记录。
- A5：搜索模式只提供“原生搜索”和“OpenAI 搜索”，未显式配置时选择 OpenAI 搜索；OpenAI 模式显示模型选择器并默认选择 `openai/gpt-5.6-luna`；模型未配置或无可用凭据时阻止保存并显示明确提示。
- A6：网页搜索并行限制接受 1–10 的整数，未显式配置时为 3，后续网页搜索调用受保存值限制。
- A7：子任务并行限制接受 1–10 的整数，未显式配置时为 3，后续子任务执行受保存值限制。
- A8：错误重试上限接受 0–100 的整数，未显式配置时为 10；0 禁用错误重试，保存值限制后续模型请求的自动重试次数。
- A9：保存失败时不误报成功，关闭存在未保存修改的面板仍执行现有确认流程。

# Constraints and invariants

- 复用现有全局配置接口和字段：`snapshot`、`websearch`、`parallel_limit`、`provider_retry`；IDE 插件自动更新使用插件侧持久化配置，不复用 OpenCode 后端的 `autoupdate`。
- `parallel_limit.websearch` 与 `parallel_limit.subagent` 必须为 1–10 的整数；`provider_retry.max_retries` 必须为 0–100 的整数。
- 已确认的运行时默认值必须与表单显示一致，不能只做视觉默认值。
- 保存后的值影响后续操作；已在执行的操作不被中途取消或重排。
- 用户图片仅作背景参考，不定义像素级或额外布局要求。

# Decisions

- 用户已指定网页搜索并行数和子任务并行数默认均为 3。
- 用户已指定错误重试上限默认 10 次。
- 已确认：“自动更新”只控制 IDE 插件更新；OpenCode 后端自身的 `autoupdate` 保持原状。
- 已确认：“原生搜索”沿用现有 Exa/Parallel 路径；“OpenAI 搜索”使用 OpenAI `/alpha/search` 路径。
- 已确认：OpenAI 搜索显示模型选择器，默认模型固定为 `openai/gpt-5.6-luna`。
- 已确认：所选 OpenAI 搜索模型未配置或没有可用凭据时阻止保存并明确提示，不自动回退原生搜索。
- 已确认：“常用设置”只展示本次需求的配置，不保留现有常规页中的用户名、分享模式和工作目录。
- 已确认：“常用设置”位于标签栏第一项，打开设置时默认进入该页。
- 已确认：所有指定默认值都是未写入配置时的实际运行时默认值，设置页必须与实际行为一致。
- 已确认：网页搜索和子任务并行数最大为 10；错误重试上限最大为 100。
- 已确认：数值输入为空、小数或越界时保留输入、显示字段级错误并阻止保存，不自动截断或恢复默认值。
- 已确认：两张图片仅作背景参考；实现沿用现有设置面板风格，无需按图逐项复现。
- 已确认：未显式配置搜索设置时，运行时仍尝试 `openai/gpt-5.6-luna`；模型或凭据不可用时返回明确配置错误，不回退 Exa/Parallel。
- 详细说明采用始终可见的行内文案，以满足无需额外交互即可阅读的要求；若图片显示其他明确形式，以图片为准重新确认。
- 仓库事实：并行队列与错误重试字段及默认值已经存在，本 change 只需接入设置界面并验证，不新增第二套机制。
