# WebGUI 推理内容 HTML 注释过滤设计

## 目标

避免新版模型输出的 `<!-- ... -->` 出现在推理内容中，同时保持现有 Markdown 渲染、安全边界和持久化数据不变。

## 设计

仅在 `ReasoningPart` 展示前移除单行或多行 HTML 注释，并兼容模型可能添加的前置反斜杠。过滤后的文本用于空内容判断和 `MarkdownRenderer` 展示；原始 `part.text` 不修改。

不启用原始 HTML 解析，不增加依赖，也不改变普通助手消息。推理代码块中的 HTML 注释同样会被隐藏，这是本次最小实现的明确取舍。

## 验证

增加一项 `ReasoningPart` 组件测试，验证：

- HTML 注释不显示。
- 注释前后的推理文字保留。
- 内容过滤为空时仍只显示思考时长标签。
