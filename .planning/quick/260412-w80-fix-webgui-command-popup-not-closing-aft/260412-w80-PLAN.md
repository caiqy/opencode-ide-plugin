<objective>
Fix the WebGUI slash command popup reopening immediately after selecting a command, and auto-append a trailing space after the inserted command text.

**Root cause:** When a command like `/help` is selected via Enter, `insertCommand()` replaces the editor text with `/help` and calls `resetState()` (sets `showPopover=false`). But the text change triggers `editor.registerUpdateListener` → `handleTextChange()` → `extractCommandQuery()`, which sees `/help` as a valid command trigger (query `"help"` has no whitespace) and returns the query — causing `setShowPopover(true)` again, immediately reopening the popup.

**Fix:** Append a trailing space to the inserted command text so it becomes `/help `. When `extractCommandQuery()` subsequently runs, the query `"help "` contains whitespace → `WHITESPACE_REGEX.test(query)` returns `true` → function returns `null` → popup stays closed.
</objective>
