# Quick Task 260412-w80: Fix WebGUI command popup not closing after selection

**One-liner:** Trailing space appended to inserted slash command text so extractCommandQuery's whitespace check prevents popup from reopening.

## What Changed

### Task 1: Append trailing space to inserted command text (`82e1243dc`)

Changed the `insertCommand()` template literal in `CommandHandler.tsx` from `` `/${metadata.name}` `` to `` `/${metadata.name} ` `` (added trailing space). This single-character fix resolves both issues:

1. **Popup closes:** After insertion, `extractCommandQuery()` sees query `"help "` which contains whitespace → returns `null` → popup stays closed
2. **Space auto-appended:** Cursor positioned after the space so user can immediately type next word

### Task 2: Regression test for extractCommandQuery whitespace rejection (`8b732db61`)

Created `utils.test.ts` with 4 tests using a real Lexical editor environment:

- `/help ` with trailing space → returns `null` (regression guard)
- `/hel` without whitespace → returns `"hel"` (normal detection)
- `/` just trigger → returns `""` (empty query)
- `hello /cmd` non-whitespace before slash → returns `null` (leading content check)
